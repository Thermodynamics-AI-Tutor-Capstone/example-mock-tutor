# Kelvin MCP pilot

Anyone can connect to the public, read-only Streamable HTTP MCP at `https://kelvin-mcp.vercel.app/mcp` with **No authentication** in ChatGPT or **No sign in** in Claude. This public hostname does not expose OAuth discovery or accept account tokens, and all five public tools explicitly advertise `noauth`. No invite or Kelvin account is needed. To save learning records across sessions, use `https://kelvin-mcp-account.vercel.app/mcp/account`, choose OAuth sign-in, then create a Kelvin account with a name and password. There is no course invite. A Claude Free account is documented to allow one custom connector, so a student who wants personal records should choose the account URL.

The professor dashboard is at `https://kelvin-professor-dashboard.vercel.app`. The demo login is `username` / `password` and contains made-up records only. **Sign in as an instructor** requires an operator-created instructor account to show live records. The Vercel dashboard sends registration, token exchange, and instructor data requests through a fixed-route serverless proxy to the Mac mini. OAuth sign-in uses the separate `kelvin-mcp-account.vercel.app` gateway, and student records remain stored on the Mac mini. The dashboard does not grant live access from the demo credentials.

The server offers course cards, misconception cards, and selected teaching skills from `../agent/` to everyone. A self-registered student can explicitly save a learning reflection; a direct DeepSeek API call classifies it when configured. The server never sees ordinary Claude messages unless Claude invokes a tool with that text. Instructors receive aggregates from at least five students, plus named records only for students who enabled instructor sharing. Student names are self-entered and unverified.

## How Claude discovers thermodynamics content

The MCP handshake identifies the server as **Kelvin: Penn State ME 300 Engineering Thermodynamics** and explains the workflow: use `course_map` once to orient, then `search_course` and `get_card` for the relevant thermodynamics concept or misconception. The five public tool descriptions also name thermodynamics and state when to call each tool. The course map identifies the actual Summer 2023 Penn State course source. Topic cards draw on the course files; misconception cards draw on cited education research. `studyCardStatus` records how a derived study note was prepared, not whether the underlying course is real. Tool descriptions and server instructions can guide Claude's selection, but Claude controls whether it calls a tool in a given conversation.

## Local run

Use Node 22+ and `npm ci` in this directory. Set `DEEPSEEK_API_KEY` in the process environment using the existing Kelvin secret source. Set `KELVIN_MCP_DATA_DIR` to a private persistent directory. Run `node admin.mjs provision-student ID` to generate a test token, then `npm start`. Keep the token out of logs and chat. The server binds to `127.0.0.1:3337` by default.

## Mac mini deployment

The launch agent starts the service from a private directory on the Mac mini. Tailscale Funnel on HTTPS port 8443 proxies to local port 3337. Port 443 is reserved for an existing private Tailscale Serve service. Two Vercel gateways expose standard HTTPS port 443: `kelvin-mcp.vercel.app` forwards only anonymous `/mcp`, while `kelvin-mcp-account.vercel.app` forwards OAuth and the signed-in endpoint. Both forward to the Mac mini Funnel. Run `tailscale funnel status` to verify that only port 8443 is public and that the Mac mini's port 443 remains tailnet-only.

Every request that reaches the Mac mini is recorded as one JSON object in `KELVIN_MCP_DATA_DIR/request-logs/YYYY-MM-DD.jsonl` and in the launch agent's stdout log. Fields include a request ID, UTC time, method, path, status, duration, gateway-reported client IP, user agent, MCP method and tool name, and account ID when authenticated. The Vercel functions also log request metadata, including GET probes that never reach an MCP tool. These logs do not include OAuth codes, passwords, bearer tokens, request bodies, or learning statements. An IP address is not a verified person; anonymous users remain anonymous. Vercel's own request logs cover requests rejected before the gateway function runs.

Course accounts, OAuth client registrations, and learning records live in private JSON files under `KELVIN_MCP_DATA_DIR`. Student account creation is open. To create an instructor account, derive a scrypt password hash and random salt locally, then use `mcp/deploy/admin-mac-mini.sh instructor-hash ID NAME SALT SCRYPT_HASH` on the Mac mini. Do not pass the plaintext password to the Mac mini command or store it in the repository. Use `disable-account ID` to block sign-in, or `delete-student ID` to remove a student's records. The admin wrapper points at the service's data directory. Back up that directory privately if the pilot lasts beyond testing.

Kelvin does not currently verify Penn State identity or import a roster. The student's name is self-entered. A student can enable instructor sharing on the sign-in page and change it later with the `share_with_instructor` tool. Authenticated instructors can see named records only for students who enabled sharing. Refresh tokens rotate and have no fixed expiration while the account remains enabled; a disconnected client may still need to sign in again if it loses its token.
