# Round 3: the accuracy harness, same students as round 2 (2026-09-24)

**What changed since round 2** (PR #10, `main` a4dffc9):
- **Solve first:** new problems are solved out of sight by deepseek-flash with the verified tools, and the result goes to the tutor as a reference.
- **New tools:** `calculate` (exact arithmetic with units) and `check_constraints` (deterministic physics checks).
- **Rules 6, 7 and 14** rewritten.
- **Seven styles merged into three,** and the course-file tools switched off.

**Same personas as round 2** (`eval/students-r2.yml`), so the differences are the harness, not the students:
10 Claude (Opus) students, 30 chats, 194 student messages, on production. Two Opus reviewers graded
every chat. Raw data (git-ignored): `data/sim-runs/r3b/`.

A first attempt (`data/sim-runs/r3/`) was abandoned partway. Lance's Mac went into lid-closed sleep, and
every student request open at that moment lost its connection, although the server had saved Kelvin's
replies. Server logs, database rows and 8 concurrent test requests all showed the server itself was
fine. The re-run kept the Mac awake with `caffeinate`.

## What's left

1. **Confident reasoning errors in side remarks.** None of the 16 errors was a table value. All are
   labels, signs, algebra or recall, and most were held until the student pushed back:
   - calling u_fg (2087 kJ/kg) "the latent heat"; the latent heat is h_fg = 2256.4
   - stirring work W written as "a tiny positive" in ΔU = Q − W; it should be negative
   - "the break-even compressor efficiency is exactly the back-work ratio" (0.470 vs 0.553)
   - "turbine efficiency has the ideal state in the numerator"; it belongs in the denominator
   - "constant cp isn't defined for steam"; Table A-2 lists it
   - a reheat heat slice of 402 kJ/kg from mismatched states; it should be 386.1
   - a parallel-flow limit taken from the wrong part of the problem (47 °C vs 41.7 °C)

   `calculate` and `check_constraints` only help when Kelvin calls them. These claims are
   definitions and conventions it states from memory. The next lever is a short verified "definitions
   and conventions" card set (latent heat = h_fg, the sign of each work, efficiency ratios), or asking
   the student instead of asserting.
2. **Course claims still slip through:** "this course (Turns & Pauley) uses the Çengel form", "graders
   want to see Q − W", and a course card called "a stub" (an internal leak).
3. **Glitch regression, all in one student's chats (Priya's):** one reply that was only raw
   `<｜｜DSML｜｜tool_calls>` markup, one repeated paragraph, and self-notes like "I'll compute the
   true answer". DeepSeek sometimes writes its tool call as text. The harness should catch that markup,
   run the call or retry, and never send it to the student.
4. **Re-tests repeat across chats** (the same bathtub-vs-coffee probe), so by the later chats they
   measure recall, not transfer.
5. **Jev's misconception read got worse** (live recall 76% → 64%, precision 54% → 42%) while the
   tutor's catch rate got better. More evidence that Jev isn't what drives the repairs.
6. **Style fit is up only slightly with 3 styles** (51% → 56%). The biggest miss is still Check My
   Work when a concept question fits better (33 replies).
