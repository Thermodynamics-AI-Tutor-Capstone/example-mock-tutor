Tables

[handwritten] $$x = \frac{v - v_f}{v_g - v_f} = \frac{u - u_f}{u_g - u_f} \ldots$$

[handwritten] $$v = x\,v_g + (1-x)v_f$$
[handwritten] $$= x\,u_g + (1-x)u_f$$
[handwritten] $$\vdots$$
