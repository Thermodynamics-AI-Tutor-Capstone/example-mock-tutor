# Entropy example

- Consider a reversible Carnot cycle:
  - 1-2: reversible, isothermal heat addition
  - 2-3: reversible, adiabatic expansion
  - 3-4: reversible, isothermal heat removal
  - 4-1: reversible, adiabatic compression
- If:
  - Qin = 6 kJ
  - TH = 900 K
  - TL = 300 K
- Find:
  - Thermal efficiency
  - Qout
  - Change in entropy of the working fluid for each process

[handwritten] $T_H = 900\ \text{K}$ (boxed)

[figure] A cycle diagram: a reservoir box labelled $T_H = 900\ \text{K}$ at the top with an arrow downward labelled $\dot{Q}_{in}$ [?] ($Q_{in} = 6\ \text{kJ}$) into a circle labelled "cycle"; an arrow points out to the right labelled $\bar{W}_{net}$; an arrow points downward out of the cycle labelled $Q_{out}$ into a boxed reservoir at the bottom labelled $T_L = 300\ \text{K}$.

[handwritten] $\eta_{th} = \dfrac{\bar{W}_{net}}{Q_{in}} = 1 - \dfrac{T_L}{T_H}$

[handwritten] $Q_{in} = \bar{W}_{net} + Q_{out}$

[handwritten] $\Delta S = \int \dfrac{\delta Q}{T}\Big|_{rev}$

[handwritten] Assume: S.C.S. : quasi-eq.

## Page 3

Entropy example

[handwritten] $\eta_{th} = 1 - \dfrac{T_L}{T_H} = 1 - \dfrac{300}{900} = \dfrac{2}{3} \rightarrow \eta_{th} = 67\%$

[handwritten] $Q_{out} \rightarrow$ rev. : $\dfrac{Q_L}{Q_H} = \dfrac{T_L}{T_H} \rightarrow Q_L = Q_H\left(\dfrac{T_L}{T_H}\right) = 6\left(\dfrac{1}{3}\right)$

[handwritten] $\underline{Q_L = 2 \text{ kJ}}$

[handwritten] $\rightarrow Q_{in} = W_{net} + Q_{out} \rightarrow W_{net} = \eta_{th}\,Q_{in} = \left(\dfrac{2}{3}\right)(6) = 4 \text{ kJ}$

[handwritten] $Q_{out} = Q_{in} - W_{net} = 6 - 4 = \underline{2 \text{ kJ}}$
