## Page 2
Example 1
$T=310$ K, $v=15$ m³/kg → find P, h

[handwritten] ("T=310" underlined)
→ Table D.1 → $v$? $v_g, v_f$ ⇒ $v_f < v < v_g$ ⇒ mixture
→ $P = P_{sat} = 6.231199$ kPa
→ $x = \dfrac{v - v_f}{v_g - v_f} = \dfrac{15 - 0.001}{22.903 - 0.001} = 0.655$
→ $h = x h_g + (1-x) h_f$
$= (0.655)(2567.9) + (1-0.655)(154.4)$
**ANSWER:** $h = 1735.25$ kJ/kg (boxed)
$h_f < h < h_g$
