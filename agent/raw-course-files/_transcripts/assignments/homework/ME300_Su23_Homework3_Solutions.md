⑥ **Given:** $c_v = 700 \text{ J/kg-K}$  $T_1 = 300\ \text{K}$  Assume: ideal gas (+1)
$c_p = 900 \text{ J/kg-K}$  $T_3 = 800\ \text{K}$  $c_p = \text{const.}$ (+1)

Process 1-2: $\Delta u = c_v \Delta T$ (+3) → $\boxed{\Delta u = 0\ \text{J/kg}}$ (+1)
$\Delta h = c_p \Delta T$ (+3) → $\boxed{\Delta h = 0\ \text{J/kg}}$ (+1)

Process 2-3: $u_3 - u_2 = c_v (T_3 - T_2) = 700(800 - 300) \Rightarrow \boxed{\Delta u = 350\ \tfrac{\text{kJ}}{\text{kg}}}$ (+1)
$h_3 - h_2 = c_p (T_3 - T_2) = 900(800 - 300) \Rightarrow \boxed{\Delta h = 450\ \tfrac{\text{kJ}}{\text{kg}}}$ (+1)

Process 3-4: $\Delta u = c_v \Delta T$ → $\boxed{\Delta u = 0\ \text{J/kg}}$ (+1)
$\Delta h = c_p \Delta T$ → $\boxed{\Delta h = 0\ \text{J/kg}}$ (+1)

Process 4-1: $u_1 - u_4 = c_v (T_1 - T_4) \Rightarrow \boxed{\Delta u = -350\ \tfrac{\text{kJ}}{\text{kg}}}$ (+1)
$h_1 - h_4 = c_p (T_1 - T_4) \Rightarrow \boxed{\Delta h = -450\ \tfrac{\text{kJ}}{\text{kg}}}$ (+1)

$\Rightarrow \sum \Delta u = 0 + 350 + 0 - 350 \Rightarrow \boxed{\sum \Delta u = 0\ \text{kJ/kg}}$ (+1)
$\sum \Delta h = 0 + 450 + 0 - 450 \Rightarrow \boxed{\sum \Delta h = 0\ \text{kJ/kg}}$ (+1)

$\Rightarrow$ This makes sense b/c this is a cycle and the system must return to its original state so all changes in properties like u and h must be zero. (+2)
