[1] A reversible process is one where if you go from State 1 to 2 along the same thermodynamic path as State 2 back to 1 both the system (+2) and its surroundings (+2) returns to the original state. (+2) In an irreversible process, the surroundings does not return to its original state due to entropy generation and the additional work it takes to return the system to its original state.

Because of this addition [transcriber note: likely intended "additional"] entropy generation and work, irreversibilities reduce the thermal efficiency of heat engines. (+2) To avoid irreversibilities, reduce friction through lubrication and heat loss through insulation. (+2)

[2] Given: $T_H = 800\ \mathrm{K}$          Assume: reversible (+1)
$T_L = 300\ \mathrm{K}$                    steady-state
$Q_L = -10\ \mathrm{kJ}$                   quasi-equilibrium processes (+1)

a) reversible $\rightarrow$ $\eta_{th} = \eta_{th,max}$ (+2) $= 1 - \dfrac{T_L}{T_H}$ (+2) $= 1 - \dfrac{300}{800}$

**ANSWER:** $\boxed{\eta_{th} = 0.625}$ (+2)

b) Carnot cycle: heat addition is isothermal at $T_H$

$$\Delta S = \oint_{rev} \frac{\delta Q}{T} \ (+2) = \frac{1}{T_H} \int \delta Q = \frac{Q_H}{T_H} \ (+2)$$

$\Rightarrow$ Reversible: $\dfrac{Q_H}{Q_L} = \dfrac{T_H}{T_L} \Rightarrow Q_H = Q_L \dfrac{T_H}{T_L} = 10\left(\dfrac{800}{300}\right)$ (+1)
$= 26.67\ \mathrm{kJ}$ (+1)

$\Rightarrow \Delta S = \dfrac{26.667}{800}\ \left[\dfrac{\mathrm{kJ}}{\mathrm{K}}\right] \rightarrow$ **ANSWER:** $\boxed{\Delta S = 33.333\ \dfrac{\mathrm{J}}{\mathrm{K}}}$ (+1)

**4** Given: $\gamma = 1.4$  [handwritten] Assume: air is ideal gas (+1)
[handwritten] $c_p, c_v = $ const (+1)
[handwritten] isentropic process (+1)

a) $P_1 = 0.1$ MPa
$v_1 = 0.2$ m³/kg
$v_2 = 0.03$ m³/kg
$\rightarrow P_1 v_1^{\gamma} = P_2 v_2^{\gamma}$ (+3)
$$P_2 = P_1\left(\frac{v_1}{v_2}\right)^{\gamma} = 0.1\left(\frac{0.2}{0.03}\right)^{1.4}$$
**ANSWER:** $\boxed{P_2 = 1.42 \text{ MPa}}$ (+1)

b) $v_1 = 0.1$ m³/kg
$T_1 = 400$ K
$T_2 = 500$ K
$\rightarrow v_2 = v_1\left(\frac{T_1}{T_2}\right)^{\frac{1}{\gamma-1}}$ (+3)
$$= (0.1)\left(\frac{400}{500}\right)^{\frac{1}{0.4}} \rightarrow \boxed{v_2 = 0.057 \frac{\text{m}^3}{\text{kg}}}$$ (+1)

c) $T_1 = 300$ K
$P_1 = 0.1$ MPa
$P_2 = 1$ MPa
$\rightarrow T_2 = T_1\left(\frac{P_2}{P_1}\right)^{\frac{\gamma-1}{\gamma}}$ (+3)
$$= 300\left(\frac{1}{0.1}\right)^{\frac{0.4}{1.4}} \rightarrow \boxed{T_2 = 579.21 \text{ K}}$$ (+1)

d) $v_1 = 0.5$ m³/kg
$P_1 = 5$ MPa
$P_2 = 10$ MPa
$\rightarrow v_2 = v_1\left(\frac{P_1}{P_2}\right)^{\frac{1}{\gamma}}$ (+1)
$$= 0.5\left(\frac{5}{10}\right)^{\frac{1}{1.4}} \rightarrow \boxed{v_2 = 0.305 \frac{\text{m}^3}{\text{kg}}}$$ (+1)

e) $P_1 = 2$ MPa
$T_1 = 400$ K
$T_2 = 750$ K
$\rightarrow P_2 = P_1\left(\frac{T_2}{T_1}\right)^{\frac{\gamma}{\gamma-1}}$ (+2)
$$= 2\left(\frac{750}{400}\right)^{\frac{1.4}{0.4}} \rightarrow \boxed{P_2 = 18.05 \text{ MPa}}$$ (+1)
