## Page 1

**EXPLAINED EXAMPLE 11 – OTTO CYCLE ANALYSIS**

① The Mazda 3 SkyActiv engine has a volume of 0.002 m³ and a compression ratio of 13. Assume the intake temperature is 300 K and intake pressure is 0.1 MPa, with a maximum cycle temperature of 1500 K. Calculate the net work, heat addition, and thermal efficiency of this engine if it runs an ideal air-standard Otto cycle. Use properties for air: R=287 J/kg-K and γ=1.4.

[handwritten] GIVEN : $\mathcal{V}_{eng} = 0.002 \text{ m}^3$
[handwritten] $= \mathcal{V}_1 - \mathcal{V}_2$
[handwritten] $r = \dfrac{\mathcal{V}_1}{\mathcal{V}_2} = 13$
[handwritten] $T_1 = 300\text{ K}$
[handwritten] $P_1 = 0.1\text{ MPa}$
[handwritten] $T_{max} = T_3 = 1500\text{ K}$

[handwritten] Find : $W_{net}$
[handwritten] $Q_{in}$
[handwritten] $\eta_{th}$
[handwritten] $\Rightarrow W_{net} = {}_1W_2 + {}_3W_4$
[handwritten] $Q_{in} = {}_2Q_3$
[handwritten] $\eta_{th} = \dfrac{W_{net}}{Q_{in}}$

[handwritten] ASSUME : ideal gas
[handwritten] ideal cycle
[handwritten] quasi-steady
[handwritten] cnst. M
[handwritten] } solve for T to solve for work and heat

[handwritten] $\longrightarrow$ STATE 1 : $T_1 = 300\text{ K}$  $P_1 = 0.1\text{ MPa}$
[handwritten] ① $\mathcal{V}_1 - \mathcal{V}_2 = 0.002 \text{ m}^3$
[handwritten] $\mathcal{V}_1 = 13\mathcal{V}_2$
[handwritten] $\Rightarrow 13\mathcal{V}_2 - \mathcal{V}_2 = 0.002 \text{ m}^3$
[handwritten] $12\mathcal{V}_2 = 0.002 \text{ m}^3$
[handwritten] $\mathcal{V}_2 = 0.00017 \text{ m}^3$
[handwritten] $\mathcal{V}_1 = 13\mathcal{V}_2 = 0.00217 \text{ m}^3$

[handwritten] ② : $P_1\mathcal{V}_1 = MRT_1 \rightarrow M = \dfrac{P_1\mathcal{V}_1}{RT_1} = \dfrac{(100000)(0.00217)}{(287)(300)}$
[handwritten] $M = 0.0025\text{ kg}$

## Page 2

→ ① $\underline{\text{State 2 :}}$ $\quad P_2 V_2 = MRT_2$

$$T_2 = \frac{P_2 V_2}{MR} \Rightarrow \quad P_2 = P_1 r^{\gamma}$$
$$= 100000\,(13)^{1.4}$$
$$= 3026775.7\ \text{Pa}$$
$$= \frac{(3026775.7)(0.00017)}{(0.0025)(287)} \Rightarrow \boxed{T_2 = 859.3\ \text{K}}$$

→ ② $\underline{\text{State 3}}:$ $\boxed{T_3 = 1500\ \text{K}}$

→ ① $\underline{\text{State 4}}:$ $\quad T_4 = T_3\left(\frac{1}{r}\right)^{\gamma-1} = 1500\left(\frac{1}{13}\right)^{0.4} \Rightarrow \boxed{T_4 = 537.7\ \text{K}}$

$\Rightarrow \overline{W}_{net} = {}_1\overline{W}_2 + {}_3\overline{W}_4 \Rightarrow$ First law: $M\Delta u = \cancel{Q} - \cancel{W}$

② $\rightarrow {}_1\overline{W}_2 = -Mc_v(T_2 - T_1) \qquad$ where $\quad R = c_p - c_v$
$$\quad = -(0.0025)(717.5)(859.3 - 300) \qquad \gamma = c_p/c_v$$
$$\quad = -1003.24\ \text{J} \qquad\qquad\qquad R = \gamma c_v - c_v$$
$$\qquad\qquad\qquad\qquad\quad\ \ c_v = \frac{R}{\gamma - 1} = \frac{287}{0.4} = 717.5\ \text{J/kg-K}$$

① $\rightarrow {}_3\overline{W}_4 = -Mc_v(T_4 - T_3)$
$$\quad = -(0.0025)(717.5)(537.7 - 1500)$$
$$\quad = 1726.13\ \text{J}$$

$$\Rightarrow \overline{W}_{net} = {}_1\overline{W}_2 + {}_3\overline{W}_4 \rightarrow \boxed{\overline{W}_{net} = 772.89\ \text{J}}$$

[transcriber note: as written $1726.13 - 1003.24 = 722.89$ J, so the boxed sum appears to contain an arithmetic slip, though $772.89$ is what is written on the page, both in this line and in the boxed result.]
