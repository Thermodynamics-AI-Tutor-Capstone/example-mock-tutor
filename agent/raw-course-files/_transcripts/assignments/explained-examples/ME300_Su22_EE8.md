**EXPLAINED EXAMPLE 8 – ISENTROPIC EFFICIENCY**

① A steam turbine operates with an inlet temperature of 780 K and inlet pressure of 3 MPa. The exit pressure of the turbine is 0.7 MPa and if the mass flow is 450 kg/s, the work output of the turbine is 177.7 MW. Assuming steady, adiabatic operation, what is the final temperature of the fluid and the isentropic efficiency of the turbine?

[handwritten] Given : $T_1 = 780\ \text{K}$  [handwritten] Find : $T_2$  [handwritten] Assume : S.C.S.
[handwritten] ② $P_1 = 3\ \text{MPa}$  [handwritten] : $\eta_{\text{turb}}$
[handwritten] $P_2 = 0.7\ \text{MPa}$  [handwritten] ① : Steady-flow
[handwritten] $\dot{m} = 450\ \text{kg/s}$  [handwritten] : $\Delta ke = \Delta pe = 0$
[handwritten] $\dot{W}_{\text{out}} = 177.7\ \text{MW}$  [handwritten] : $\dot{Q} = 0$

[handwritten] ② Energy equation: $\dot{m}\left(\Delta h + \cancel{\Delta ke} + \cancel{\Delta pe}\right) = \cancel{\dot{Q}} - \dot{W}$
[handwritten] $\dot{m}\,\Delta h = -\dot{W}$
[handwritten] $h_2 = h_1 - \dfrac{\dot{W}}{\dot{m}} \rightarrow$ find $T_2$ from $h_2$ & $P_2$

[handwritten] ① State 1 : $\left.\begin{array}{l} P_1 = 3\ \text{MPa} \\ T_1 = 780\ \text{K} \end{array}\right\}$ Table D.2 $\rightarrow$ $P_1 = 3\ \text{MPa}$, $T_1 > T_{\text{sat}} \rightarrow$ vapor
[handwritten] : Table D.3L $\rightarrow$ $h_1 = 3472.6\ \dfrac{\text{kJ}}{\text{kg}}$
[handwritten] $s_1 = 7.2557\ \dfrac{\text{kJ}}{\text{kg}\cdot\text{K}}$

[handwritten] ② State 2 : $h_2 = h_1 - \dfrac{\dot{W}}{\dot{m}} = 3472.6\ \dfrac{\text{kJ}}{\text{kg}} - \dfrac{177.7}{450}\ \dfrac{\text{MJ}}{\text{kg/s}}$  [handwritten] (units as written: $\dfrac{\text{MJ}}{\text{kg/s}}$ [?])
[handwritten] $h_2 = 3077.7\ \dfrac{\text{kJ}}{\text{kg}}$
[handwritten] : Table D.2 $\rightarrow$ $P_2 = 0.7\ \text{MPa}$
[handwritten] $h_2 > h_g \rightarrow$ vapor

[transcriber note: the work-per-mass term is written as $\frac{177.7}{450}$ with the numerator labeled "MJ" and denominator "kg/s" — the result is converted to kJ/kg.]

! Table D.3H → $h_2 = 3077.7 \ \frac{\text{kJ}}{\text{kg}}$

$\boxed{T_2 \approx 580 \ \text{K}}$ (closest temp)

① $\Rightarrow \eta_{turb} = \dfrac{\dot{W}_{act}}{\dot{W}_{ideal}} \rightarrow \dot{W}_{ideal} = -\dot{m}\,(h_{2s} - h_1)$
where $h_{2s}$ from isentropic expansion

② $\Rightarrow$ State 2s: $P_2 = 0.7 \ \text{MPa}$
$s_{2s} = s_1 = 7.2557 \ \frac{\text{kJ}}{\text{kg}}$
! Table D.2 → $s_{2s} > s_g$ → vapor
! Table D.3H → $h_{2s} \approx 3031.9 \ \frac{\text{kJ}}{\text{kg}}$

① $\Rightarrow \dot{W}_{ideal} = -\dot{m}\,(h_{2s} - h_1)$
$= -450\,(3031.9 - 3472.6)$
$= 198{,}315 \ \text{kW}$

② $\Rightarrow \eta_{turb} = \dfrac{177.7}{198{,}315} \rightarrow \boxed{\eta_{turb} = 0.896}$
