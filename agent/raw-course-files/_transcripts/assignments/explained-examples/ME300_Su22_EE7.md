**EXPLAINED EXAMPLE 7 – ISENTROPIC EXPANSION**

① Steam expands isentropically from a starting temperature of 500 K and pressure of 2 MPa to a saturated vapor. Determine the final temperature and pressure of the fluid at the end of the process, and draw this process on a T-s diagram. What would the final temperature be if air, starting at the same temperature and pressure, ended at the same final pressure? Assume the following properties for air: $c_p=1000$ J/kg-K and $c_v=714.29$ J/kg-K.

[handwritten] Given: $T_1 = 500$ K  Find: $T_2, P_2$ steam  Assume: isentropic
[handwritten] ② $P_1 = 2$ MPa  $T_2, P_2$ air  ① $H_2O = S.C.S$
[handwritten] $x_2 = 1$     air = ideal
[handwritten] $s_2 = s_1$     quasi-steady

[handwritten] → Steam State 1 : $T_1 = 500$ K   } Table D.2  $P_1 = 2$MPa
[handwritten] ② $P_1 = 2$MPa  $T_1 > T_{sat} \rightarrow$ vapor

[handwritten] → Table D.3K → $s_1 = 6.4205 \frac{kJ}{K}$

[handwritten] → Steam State 2 : $x_2 = 1$
[handwritten] ① $s_2 = s_1 = 6.4205 \frac{kJ}{K}$

[handwritten] → Table D.1. : $s_2 = s_g \rightarrow$ in between $T_a = 470$ K
[handwritten]                $T_b = 475$ K

[handwritten] → linear interpolation: $T_2 = \left(\frac{s_2 - s_a}{s_b - s_a}\right)(T_b - T_a) + T_a$

[handwritten] $$= \left(\frac{6.4205 - 6.4538}{6.4164 - 6.4538}\right)(475 - 470) + 470$$

**ANSWER:** [handwritten] $\boxed{T_2 = 473.615\ \text{K}}$

[handwritten] Sat : $P_a = 1.455\ \text{MPa}$ $P_b = 1.6116\ \text{MPa}$

[handwritten] ③ → linear interpolation
$$P_2 = \left(\frac{s_2 - s_a}{s_b - s_a}\right)(P_b - P_a) + P_a$$
$$= \left(\frac{6.4265 - 6.4538}{6.4164 - 6.4538}\right)(1.6116 - 1.455) + 1.455$$

[handwritten] **ANSWER:** $\boxed{P_2 = 1.573\ \text{MPa}}$

[handwritten] ① [figure] $T$–$s$ diagram: vertical axis labelled $T$, horizontal axis labelled $s$; a saturation dome curve drawn (rising left branch and falling right branch meeting at a peak); a dashed vertical line drawn at constant entropy, with state ① marked with a dot on this line above the curve and an arrow pointing downward along the line; state ② marked with a dot where the dashed line crosses the descending right branch of the dome; the dashed line continues to the $s$ axis, labelled $s_2 = s_1$.

[handwritten] → our : isentropic relations
[handwritten] ②
$$T_2 = T_1\left(\frac{P_2}{P_1}\right)^{\frac{\gamma-1}{\gamma}} \qquad \text{where } \gamma = \frac{c_p}{c_v} = \frac{1000}{714.29} = 1.4$$
$$= 500\left(\frac{1.573}{2}\right)^{\frac{0.4}{1.4}}$$

[handwritten] **ANSWER:** $\Rightarrow \boxed{T_2 = 466.84\ \text{K}}$
