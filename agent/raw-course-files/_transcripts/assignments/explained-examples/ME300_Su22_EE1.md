## Page 1
**EXPLAINED EXAMPLE 1 – P-v-T EQUATION OF STATE**

[handwritten] (red circled "1" beside the problem statement; green circled "2" beside part a — step markers used throughout the solution)

An inventor is testing out different processes for cooling air in a piston-cylinder arrangement from the same initial state. In both processes, the mass-specific volume of the chamber reduces from $v_1 = 10\text{ m}^3/\text{kg}$ to $v_2 = 5\text{ m}^3/\text{kg}$, but Process A is isobaric and Process B is isothermal. Answer the following questions about these two processes if the temperature at state 1 is $T_1 = 1000\text{ K}$. For air, $R = 287\text{ J/kg-K}$ and $c_v = 714\text{ J/kg-K}$. List your assumptions.

a. Draw both processes on the same P-v diagram and label the state points – State 1, State 2A (after Process A), and State 2B (after process B).

b. Calculate $T_2$ and $P_2$ for both processes.

[handwritten]
(1) Given:
- $v_1 = 10\text{ m}^3/\text{kg}$
- $v_2 = 5\text{ m}^3/\text{kg}$
- $P_{2A} = P_1$
- $T_{2B} = T_1$
- $T_1 = 1000\text{ K}$
- $R = 287\text{ J/kg-K}$
- $c_v = 714\text{ J/kg-K}$

(2) Assume:
- air → ideal gas
- quasi-steady
- Process A $P_2 = P_1$
- Process B $T_2 = T_1$
- sealed, $M = \text{const}$

a) [figure] P-v diagram (P vertical; v horizontal in $[\text{m}^3/\text{kg}]$). Vertical dashed lines at $v_2 = 5$ and $v_1 = 10$. State 1 at $v_1 = 10$ at pressure $P_1$ (horizontal dashed line labelled $P_1$ on the left). State 2A at $v_2 = 5$, same pressure $P_1$; horizontal line from 1 to 2A labelled "A" with arrow pointing left. State 2B at $v_2 = 5$ at higher pressure; curved line (hyperbola) from 1 up-left to 2B with arrow toward 2B; the curve is labelled as the isotherm "$T_1$" by a dashed extension to the right of state 1.

(1) Process A: $P = \text{const}$
(2) Process B: $T = \text{const}$
$$Pv = RT$$
$$P = \frac{RT}{v}, \quad P \sim \frac{1}{v} \text{ if } T = \text{const}$$

(1) b) Process A:
State 1: $P_1 v_1 = RT_1$ (checkmarks over $v_1$, $R$, $T_1$ as known) →
$$P_1 = \frac{RT_1}{v_1} = \frac{(287)(1000)}{10} \Rightarrow P_1 = 28{,}700\text{ Pa}$$
State 2: **ANSWER:** $P_2 = P_1 = 28{,}700\text{ Pa}$
$$T_2 = \frac{P_2 v_2}{R} = \frac{(28700)(5)}{287} \Rightarrow$$
**ANSWER:** $T_2 = 500\text{ K}$
