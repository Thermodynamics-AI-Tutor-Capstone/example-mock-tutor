# Final exam (Summer 2021), problem 3: Closed piston-cylinder process diagram: work, heat, entropy, and cycle classification

## Problem

Two quasi-equilibrium processes, A and B, occur between the same end states inside a closed piston-cylinder device with constant mass, as shown. In the $P$--$\mathcal{V}$ diagram, Path B is the upper arc from state 1 to state 2, and Path A is the lower arc from state 2 to state 1. (a) In both processes, is work being done on the fluid or by the fluid? Options: on the fluid / by the fluid. (b) Which is true about the work for each process? Options: $W_A > W_B$, $W_A = W_B$, $W_A < W_B$. (c) Which is true about the heat transfer of the two processes? Options: $Q_A > Q_B$, $Q_A = Q_B$, $Q_A < Q_B$, insufficient information. (d) Which is true about the entropy change of the system over the two processes? Options: $\Delta S_A > \Delta S_B$, $\Delta S_A = \Delta S_B$, $\Delta S_A < \Delta S_B$, insufficient information. (e) If the system went from State 1 to 2 along Path A, and then back from State 2 to 1 along Path B (reversing Path B's direction), which type of cycle would this be? Options: power cycle, refrigeration cycle, insufficient information. (30 points total)

## What it tests

- Students can determine work sign from volume change.
- Students can compare process work by area under the path on a $P$-$\mathcal{V}$ diagram.
- Students can use the first law to infer heat transfer when internal energy change is path-independent.
- Students can recognize entropy as a property and classify a cycle by direction on a $P$-$\mathcal{V}$ loop.

## Assumptions the solution expects

- Closed system with constant mass.
- Quasi-equilibrium processes.
- Same end states 1 and 2 for the two processes.
- For the cycle part: Path A is traversed 1 to 2 and then Path B is traversed 2 to 1 in reverse direction.

## Where students go wrong

- Misreading the arrow direction on Path A in the diagram when determining whether the fluid is expanding or being compressed.
- Comparing work by path length instead of area under the curve.
- Treating heat transfer as equal to work instead of using $\Delta U = Q - W$ and path-independence of internal energy.
- Treating entropy change as path-dependent instead of recognizing entropy is a property.
- Calling the loop a power cycle without checking the direction around the cycle on the $P$-$\mathcal{V}$ diagram.

## How it is graded

Each subpart rewards the correct choice and a short, correct justification; total 30 points across the five subparts.

## Final answers (hidden — for checking only)

- Work direction: by the fluid
- Work comparison: $W_A < W_B$
- Heat transfer comparison: $Q_A < Q_B$
- Entropy change comparison: $\Delta S_A = \Delta S_B$
- Cycle type: Refrigeration cycle
