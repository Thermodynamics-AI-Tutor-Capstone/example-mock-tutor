## Problem

Calculate the final state point for isentropic processes in air, where $\gamma = 1.4$. (a) Find $P_2$ for $v_1 = 0.2 \ \mathrm{m^3/kg}$, $P_1 = 0.1 \ \mathrm{MPa}$, $v_2 = 0.03 \ \mathrm{m^3/kg}$. (b) Find $v_2$ for $v_1 = 0.1 \ \mathrm{m^3/kg}$, $T_1 = 400 \ \mathrm{K}$, $T_2 = 500 \ \mathrm{K}$. (c) Find $T_2$ for $P_1 = 0.1 \ \mathrm{MPa}$, $T_1 = 300 \ \mathrm{K}$, $P_2 = 1 \ \mathrm{MPa}$. (d) Find $v_2$ for $P_1 = 5 \ \mathrm{MPa}$, $v_1 = 0.5 \ \mathrm{m^3/kg}$, $P_2 = 10 \ \mathrm{MPa}$. (e) Find $P_2$ for $T_1 = 400 \ \mathrm{K}$, $P_1 = 2 \ \mathrm{MPa}$, $T_2 = 750 \ \mathrm{K}$.

## What it tests

- Students can apply constant-$\gamma$ isentropic relations for ideal gases.
- Students can select the appropriate relation among $P$, $v$, and $T$.
- Students can solve for final state properties.

## Assumptions the solution expects

- air is ideal gas
- constant specific heats
- isentropic process

## Where students go wrong

- Mixing the exponents in the isentropic relations, e.g. using $\gamma-1$ where $\gamma$ is required.
- Inverting the temperature-specific-volume ratio: using $T_2/T_1$ instead of $T_1/T_2$ when solving for $v_2$.
- Using the isobaric or isothermal ideal gas relation instead of isentropic relation.
- Algebraic errors in raising ratios to powers such as $1/\gamma$ or $(\gamma-1)/\gamma$.

## How it is graded

Points for assumptions and for each correct isentropic relation; answers awarded one point each.

- $T_2 (c)$: 579.21 K
- $v_2 (d)$: 0.305 m^3/kg
- $P_2 (e)$: 18.05 MPa
