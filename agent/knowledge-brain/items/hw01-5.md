## Problem

Identify the proper SI unit for each property – use the book as a reference: a. Pressure b. Temperature c. Volume d. Energy e. Power f. Length g. Time h. Mass i. Velocity j. Density

## What it tests

- Students can identify SI units for common thermodynamic properties.

## Assumptions the solution expects



## Where students go wrong

- Using Celsius instead of kelvin for temperature.
- Using liters instead of m^3 for volume.
- Using grams instead of kilograms for mass.
- Using km/h instead of m/s for velocity.
- Using kg/m^2 instead of kg/m^3 for density.

## How it is graded

+1 for each correct SI unit.

## Final answers (hidden — for checking only)

- Pressure: Pa
- Temperature: K
- Volume: m^3
- Energy: J
- Power: W
- Length: m
- Time: s
- Mass: kg
- Velocity: m/s
- Density: kg/m^3
