# Homework 2 (Summer 2023), problem 1: Thermodynamic process vs thermodynamic cycle

## Problem

What's the difference between a thermodynamic process and a thermodynamic cycle? Define each and describe their differences. How does the state of the system change for each?

## What it tests

- Students can define a thermodynamic process and a thermodynamic cycle and describe how the system state changes for each.

## Assumptions the solution expects



## Where students go wrong

- Not stating that a process ends at a different state.
- Defining a cycle as just multiple processes without explicitly mentioning the return to the original state.
- Thinking a cycle is the same as a process.

## How it is graded

Points awarded for correct definitions: process (+7), cycle (+8).

## Final answers (hidden — for checking only)

- Process: A system undergoes a change from one state to another; at the end the system is at a different state than at the beginning.
- Cycle: A system undergoes a series of processes and the state of the system returns back to its original state.
