## Problem

5. (20 points) Consider the cycle shown in the T-v diagram, where isobars are shown in dotted lines, and answer the following questions assuming the working fluid is an ideal gas:
a. Fill in the table below indicating whether each property increases, decreases, or is constant for each process:
| Process | Temperature | Pressure | Volume |
| 1-2 | | | |
| 2-3 | | | |
| 3-4 | | | |
| 4-1 | | | |
The T-v diagram has Temperature on the vertical axis and Volume on the horizontal axis; dashed isobars radiate from the origin. The cycle runs 1→2 horizontal to the right, 2→3 vertically down, 3→4 horizontally left, 4→1 diagonally up-right back to 1.
b. Re-sketch this cycle on a P-v diagram, indicating the same state points and arrows for the cycle direction. I have provided the axes and State 1 for your reference.

## What it tests

- Read process properties from a T-v diagram
- Determine whether $T$, $P$, and $v$ increase, decrease, or remain constant along ideal-gas paths
- Translate a cycle from T-v to P-v coordinates

## Assumptions the solution expects

- Working fluid is an ideal gas
- Isobars are the dotted straight lines on the T-v diagram

## Where students go wrong

- Misidentifying vertical line 2-3 as constant pressure instead of constant volume
- On horizontal line 1-2, saying pressure is constant because temperature is constant
- On 4-1, saying volume is constant instead of following an isobar with volume and temperature increasing
- Drawing isothermal steps 1-2 and 3-4 as straight horizontal/vertical lines on the P-v diagram instead of curved lines
- Not preserving cycle direction or state numbering in the P-v sketch

## How it is graded

The solution awards +1 for each correct table entry and +1 for each correct arrow/state placement in the P-v sketch.
