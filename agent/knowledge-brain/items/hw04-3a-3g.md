# Homework 4 (Summer 2023), problem 3a-3g: Steam table phase identification and property lookup for H2O

## Problem

Given the following property data for H$_2$O, designate the phase (or line/point) in T-v or P-v space and find the requested property or properties. Use the steam tables and indicate the table used.

a. $T = 440$ K, $P = 0.733679$ MPa, $v = 0.26090$ m$^3$/kg: Phase = ?, $h$ = ?, Table = ?
b. $T = 440$ K, $P = 5.00$ MPa: Phase = ?, $u$ = ?, Table = ?
c. $T = 440$ K, $P = 0.100$ MPa: Phase = ?, $v$ = ?, Table = ?
d. $T = 440$ K, $P = 0.733679$ MPa, $v = 0.200$ m$^3$/kg: Phase = ?, $h$ = ?, Table = ?
e. $T = 647.096$ K, $P = 22.064$ MPa: Phase = ?, $v$ = ?, Table = ?
f. $T = 700$ K, $P = 32$ MPa: Phase = ?, $\rho$ = ?, Table = ?
g. $T = 605$ K, $P = 6.0$ MPa: Phase = ?, $u$ = ?, Table = ?

## What it tests

- Students can compare pressure or temperature with saturation values to determine phase.
- Students can select the correct compressed-liquid, saturated, or superheated table.
- Students can use quality to evaluate properties of a two-phase liquid-vapor mixture.
- Students can interpolate between steam table entries.

## Assumptions the solution expects

- simple compressible system

## Where students go wrong

- not comparing given pressure with saturation pressure at the given temperature before choosing a table.
- using saturated table values for compressed liquid or superheated vapor states.
- for part d, using $h_f$ or $h_g$ directly instead of calculating quality $x$ for the mixture.
- using the wrong interpolation endpoints or formula for part g.
- failing to recognize the critical point in part e and the supercritical state in part f.
- not writing the table used, which the problem and grading explicitly require.

## How it is graded

Grading rewards correct phase, correct property value, and indicated table for each subpart; interpolation for part g is explicitly awarded.
