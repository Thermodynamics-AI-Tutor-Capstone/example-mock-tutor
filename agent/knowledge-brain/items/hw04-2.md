## Problem

Fill out the table for CO$_2$. Calculate $v$ using the ideal gas law ($M = 44.01$ kg/kmol), look up $v$ from the NIST Webbook, calculate the compressibility $Z$ using the NIST value of $v$, and identify the phase. Explain why CO$_2$ is no longer an ideal gas as pressure increases.

| T [K] | P [MPa] | v (ideal) [m$^3$/kg] | v (NIST) [m$^3$/kg] | Z | Phase (NIST) |
|---|---|---|---|---|---|
| 300 | 0.2 |  |  |  |  |
| 300 | 4.1 |  |  |  |  |
| 300 | 8.3 |  |  |  |  |
| 500 | 8.3 |  |  |  |  |

## What it tests

- Students can calculate specific gas constant from molecular weight.
- Students can compute ideal-gas specific volume and compare it with real-fluid NIST data.
- Students can calculate compressibility factor and identify phase from NIST data.

## Assumptions the solution expects

- ideal gas for the ideal-volume calculation
- simple compressible system for the NIST/reference properties

## Where students go wrong

- using $T$ in Celsius or $P$ in MPa directly in $v = RT/P$.
- using the universal gas constant $\bar R$ rather than $R = \bar R/M$.
- calculating $Z$ with the ideal volume instead of the NIST volume.
- assigning phase from the ideal-gas table rather than the NIST table.
- treating the 500 K, 8.3 MPa state as two-phase when the solution calls it supercritical.

## How it is graded

Each row awards 1 point each for ideal volume, NIST volume, Z, and phase; the specific gas constant and ideal-gas relation are also awarded.
